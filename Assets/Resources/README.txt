IMPORTANT: Photon PUN 2 requires all network-instantiated prefabs to live in this Resources/ folder.

Place these prefabs here:
  - Archer.prefab   (stickman player)
  - Arrow.prefab    (the fired arrow)

Steps to create a prefab:
1. Build the GameObject in the scene with all components attached
2. Drag it from the Hierarchy into this folder in the Project panel
3. Delete the original from the scene (keep only the prefab)
